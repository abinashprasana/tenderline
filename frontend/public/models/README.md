# Wren, the 3D owl

`wren.gltf` (with `wren.bin` and two WebP textures) is the owl from [Vuena/free-low-poly-animals-cc0](https://github.com/Vuena/free-low-poly-animals-cc0)
(`GLB/animal_owl.glb`), released under CC0 1.0 (public domain). Thank you, Vuena.

Changes made for Tenderline: brown feathers recoloured sea-green, the mobile LOD and the unused
`attack`, `death` and `walk` clips removed, textures resized to 1024 px WebP and kept as separate files so the content security policy needs no `blob:` exception.
